## 🏆 Featured Project: Coduelo

### ⚔️ [Coduelo](https://github.com/Yugank-563/Real-Time-Coding-Duels) | [Live Demo](https://coduelo.vercel.app/)

A **real-time 1v1 competitive coding platform** built for speed, precision, and high-stakes problem solving.

- ⚡ **Real-Time 1v1 Duels:** Powered by Socket.io with live matchmaking and instant winner detection.
- 🎯 **Multiple Battle Modes:** Random Duels, Private Room Invites, Topic Duels, and Timed Sprints.
- 🏗️ **Distributed Microservices:** 4 independent services communicating via Redis Pub/Sub & BullMQ.
- 💻 **Async Execution Pipeline:** Compiles and evaluates submissions against hidden test cases.
- 🏆 **Rankings & Analytics:** Rating-based leaderboards, match history, and detailed player profiles.
